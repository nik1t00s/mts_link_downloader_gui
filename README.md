# MTS Link Downloader GUI

Простое desktop-приложение на Python/Tkinter для скачивания доступных пользователю записей MTS Link / МТС Линк по ссылке.

Программа:

- принимает ссылку на запись;
- позволяет выбрать папку сохранения;
- скачивает видео через `yt-dlp`;
- для ссылок `record-new` MTS Link сначала получает прямые `.mp4` / `.m3u8` ссылки через API записи;
- показывает прогресс, статус и лог;
- не перезаписывает существующие файлы;
- сообщает понятную ошибку, если запись недоступна, ссылка неверная или не найдено видео.

Иногда MTS Link хранит запись как несколько медиапотоков, например экран и отдельные аудиодорожки. В таком случае программа выбирает видеопоток и все найденные аудиодорожки, а затем собирает один итоговый `.mp4` через `ffmpeg`. Если аудиодорожка одна, видео и звук копируются без перекодирования. Если аудиодорожек несколько, они сводятся в одну общую звуковую дорожку.

## Установка

Нужен Python 3.10 или новее.

```powershell
cd N:\Scripts\mts_link_downloader_gui
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

После запуска вставьте ссылку MTS Link, выберите папку и нажмите **Скачать**.

## Если запись требует авторизации

Приложение не обходит авторизацию и не подставляет cookies автоматически. Если запись открывается только после входа в аккаунт, откройте ссылку в браузере и убедитесь, что у вас есть законный доступ к записи. Если без cookies страница не отдает видео, приложение честно покажет ошибку доступа.

## Если нужен ffmpeg

Некоторые записи доступны как поток `.m3u8`. Для надежного скачивания и сборки таких видео может понадобиться `ffmpeg`.

Проверить наличие:

```powershell
ffmpeg -version
```

Если команда не найдена, установите ffmpeg и добавьте папку с `ffmpeg.exe` в `PATH`. На Windows удобно установить через Winget:

```powershell
winget install Gyan.FFmpeg
```

После установки перезапустите PowerShell или компьютер, чтобы обновился `PATH`.

## Ограничение

Приложение не обходит DRM, не взламывает доступ и не пытается обходить ограничения MTS Link. Оно скачивает только те записи, к которым у пользователя уже есть законный доступ.
